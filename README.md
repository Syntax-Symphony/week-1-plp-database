
# Database Basics Assignment

This project contains basic SQL queries for creating and managing databases as part of a database introduction assignment.

## Contents
- Create a new database (`salesDB`)
- Drop an existing database (`demo`)

## How to Use
Run the queries in the `answers.sql` file using a MySQL editor or terminal connected to your database system.

## Requirements
- MySQL or any SQL-compatible database
- Basic SQL knowledge
